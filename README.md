clox is a Lox programming language interpreter implemented in C. clox uses a bytecode VM and is from the book [Crafting Interpreters](https://craftinginterpreters.com/).<br>

The purpose of this repository was to gain experience in C, memory management, and programming language theory. It has given me the experience to start writing my own [BASIC interpreter](https://github.com/timo-zzz/basic-lang-interpreter).
